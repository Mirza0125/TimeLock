## Phase Goal

ROADMAP Goal (verbatim): A reproducible Expo SDK 57 project runs on the emulator with full quality tooling, the shared enforcement contract is frozen, and the API 36 block-launch question is answered with a working fallback before any enforcement code depends on it.

This plan's slice: **proof of reproducible, minimal native config (FND-02).** A developer runs `pnpm verify:native` and learns whether `prebuild --clean` still reproduces the same app and whether the built APK requests anything it should not.

<objective>
Turn ROADMAP success criterion 2 into two runnable gates. (1) `scripts/verify-native-config.sh`: prebuild --clean twice plus one non-clean re-run must be byte-identical; the generated manifest and accessibility XML must contain exactly the plugin's entries; android/ must be untracked. (2) `scripts/audit-apk-manifest.sh`: the built debug APK must request only allowlisted permissions, never a denylisted one, and must target the right SDK levels and keep the security-relevant manifest attributes.

Purpose: "android/ is never hand-edited" is made structural by CNG plus gitignore. What remains is to prove that regeneration is deterministic and that the shipped manifest is minimal, which matters because Play review is the top priority. The spike (Plan 01-07) is only valid if the APK does not declare the overlay permission, which is itself a background-launch exemption.
Output: two gate scripts, the permission allowlist, `scripts/gradle.sh` (reused by Plan 01-06), and the `pnpm verify:native` script.
</objective>
