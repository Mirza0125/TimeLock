## Phase Goal

ROADMAP Goal (verbatim): A reproducible Expo SDK 57 project runs on the emulator with full quality tooling, the shared enforcement contract is frozen, and the API 36 block-launch question is answered with a working fallback before any enforcement code depends on it.

This plan's slice: **the Kotlin quality gates (FND-04 second half, FND-05 JUnit half).** A developer runs `pnpm lint:kotlin` and `pnpm test:kotlin`. JUnit loads the same shared vectors Jest loads, and the block-path decision logic is pinned by an invariant test before the spike measures it.

<objective>
Wire ktlint and JUnit into the local module's own `build.gradle` (module source, never generated android/). Load the shared vectors in JUnit through Gradle test resources pointing at the single JSON file. Unit-test `BlockOutcomeDecider`, the assumption-delta "promote" invariant from Plan 01-04.

Purpose: FND-04 requires ktlint and JUnit as single commands; FND-05 requires the vectors to load in JUnit before any evaluator exists. Testing the decider before the spike means the spike's recorded outcomes come from logic already proven correct at its boundaries.
Output: .editorconfig, module build.gradle additions, two JUnit test classes, ktlint-formatted Kotlin, and package.json scripts lint:kotlin / format:kotlin / test:kotlin.
</objective>
