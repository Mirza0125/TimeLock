# ScreenLimiter

A React Native (Expo) screen-time app that lets people put daily/usage limits on any installed
app. See [docs/PRODUCT_SPEC.md](docs/PRODUCT_SPEC.md) for the full product specification.

## Prerequisites

- Node 24 (via [nvm](https://github.com/nvm-sh/nvm))
- JDK 17 at `~/.local/jdk/jdk-17`
- Android SDK at `~/Android/Sdk` (platform-tools, build-tools 36.1.0, emulator)
- AVD `Medium_Phone_API_36.1` already running as `emulator-5554`

## Quick start

```bash
. scripts/env.sh
corepack enable
pnpm install
bash scripts/run-android.sh --clean
pnpm e2e:skeleton
```

`scripts/run-android.sh --clean` prebuilds, starts Metro, builds, installs and launches the app
on the running emulator, printing `APP_RUNNING pid=<pid>` when it succeeds. `pnpm e2e:skeleton`
then proves the UI -> native -> persistence -> UI round trip, including surviving a
force-stop + relaunch.

## Never edit `android/` by hand

`android/` is generated by `expo prebuild` (Continuous Native Generation) and is gitignored.
Any change made directly inside `android/` is silently discarded the next time `expo prebuild
--clean` runs. All native Android configuration must go through Expo config plugins or the
`modules/screen-guard` native module sources instead.

## Scripts

- `scripts/env.sh` — sourceable toolchain environment (Node 24, JDK 17, Android SDK, emulator
  targeting). Source it first: `. scripts/env.sh`.
- `scripts/metro.sh start|stop|status` — background Metro bundler control.
- `scripts/run-android.sh [--clean]` — prebuild + Metro + build/install/launch on the emulator.
- `scripts/emu-ui.mjs dump|wait <selector>|tap <selector>` — uiautomator-based UI driver for
  emulator E2E scripts (selectors: `id:<testID>`, `text:<substring>`, `desc:<substring>`).
- `scripts/e2e-skeleton.sh` — proves a Home-route tap persists natively and survives a
  force-stop + relaunch.
